# Dave Desktop — 自检清单 + 录屏盲测脚本

> **目的**:把"打磨提升转化率"工作沉淀为可重复执行的验证脚本,作为 `npm run verify` 之外的"人工盲测"层。
> **使用时机**:每次发版前 / 大改 UI 与交互后 / 引导流调整后。
> **运行方式**:开发者 / QA 按本清单逐步过一遍,每条 ✅/❌,全部 ✅ 才能视为通过。

---

## 1. 自动化自检清单(CI 必跑)

> 这部分已由 `npm run verify` 覆盖,跑一遍即视为通过。

```bash
npm install           # 依赖完整
npm run typecheck     # 双 tsconfig 全绿(渲染器 + Node)
npm run test          # vitest 全部通过(目前 63 用例)
npm run build         # electron-vite build 成功,懒加载分包齐全
```

**期望产物**:

- `out/main/index.js` (CJS bundle, 包含主进程逻辑)
- `out/preload/index.js` (preload bridge)
- `out/renderer/index.html` + 多个 `assets/*.js` (懒加载分包)
- 关键分包存在:`Welcome-*.js`、`ApiKeyWizard-*.js`、`Settings-*.js`、`CommandPalette-*.js`、`KeyboardHelp-*.js`、`WorkspacePanel-*.js`

### 5.1 性能预算实测(产品规约)

> 三道预算闸均走 `checkStartupBudget` 纯函数 + 遥测打点,设置 → 关于里
> 应能看到 `first_window_shown` / `renderer_ready` / `ttfb_recorded` 事件。

| 指标                    | 预算  | 测量方法                          | ✅/❌ |
| ----------------------- | ----- | --------------------------------- | ----- |
| 冷窗口(cold_window)     | < 3s  | 主进程拉起 → 主窗口 ready-to-show | ☐     |
| 首问 TTFB               | < 5s  | 发送消息 → 首个 chunk 到达        | ☐     |
| 首启到可输入(first_run) | < 60s | 全流程,含下载/安装/引导/Key 配置  | ☐     |

**实测步骤**:

1. 清空统计,关闭并冷启动(等 5s 后再开,避免 OS 缓存)
2. 进入设置 → 关于 → 找到 `first_window_shown` 事件,记录 `elapsedMs`
3. 期望:`within = "1"` 且 `elapsedMs < 3000`
4. 配置好 API key,输入"你好"发送,记录首个字符出现的时间差
5. 期望:`ttfb_recorded` 事件 `within = "1"` 且 `ms < 5000`
6. 完整首启流程(卸载后首次启动),从双击图标到能输入首条消息应 < 60s

## 6. 录屏盲测脚本(自动操作序列)

> 用 Puppeteer / Playwright 自动化时,可参考以下序列录制短视频。
> **建议录屏时长**:每个脚本 60-120s,总共不超过 10 分钟。

### 6.1 脚本 1:首启漏斗(0-3 分钟)

```
1. 启动应用(冷启动)
2. 录屏 30s 完整三屏欢迎(手动 ←/→/Enter 翻页)
3. 进入 ApiKeyWizard,选 OpenAI,粘假 Key sk-test-123
4. "测试连接" → 失败提示出现
5. 跳过工作区 → 完成
6. 主界面 → 点"找出最近一次 commit 引入的 bug"模板
7. 设置 → 关于 → 截图 FunnelView
8. 设置 → 关于 → "重新查看欢迎页" → 再次弹欢迎页
9. 关闭应用
```

**期望**:漏斗应显示 `launched=1, onboarded=1, firstMessage=0`(模板点击不计入首问)。

### 6.2 脚本 2:键盘可达性(3-6 分钟)

```
1. 启动应用(已配置过)
2. ? 弹 KeyboardHelp → 截图
3. Esc 关闭
4. Cmd+K 弹命令面板 → 输入"新建" → Enter
5. Cmd+K → 输入"主题" → Enter
6. Alt+↑ / Alt+↓ 在会话间切换
7. ? 再次弹 KeyboardHelp → Esc
8. Cmd+, 弹 Settings → Esc
9. 关闭
```

**期望**:所有快捷键无报错,焦点正确恢复到触发元素。

### 6.3 脚本 3:中止 + 重新生成(6-9 分钟)

```
1. 启动应用,打开一个长会话
2. 输入"写一篇关于 AI 的 1000 字文章" → 发送
3. 流式输出到一半,点"停止"按钮
4. 期望:流停,partial 落为最后一条 assistant 消息(有"已停止"标记)
5. hover 该条 → 点"重新生成"
6. 期望:abort 当前流(若有),重发最后一条 user 消息
7. 关闭
```

**期望**:状态栏在停止时显示"已停止",恢复后显示"就绪"。

### 6.4 脚本 4:工作区边界(9-12 分钟)

```
1. 设置工作区为某个空目录
2. 让 Agent 读 ../package.json(越界)
3. 期望:出现批准对话框,文本含"越界 / 工作区外"警告
4. 拒绝批准 → 工具返回错误
5. 让 Agent 读 ./package.json(在 workspace 内)
6. 接受批准 → 工具成功返回
7. 关闭
```

**期望**:越界路径一定被拦下(无 path traversal),用户可清晰看到拒绝原因。
