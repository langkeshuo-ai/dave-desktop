## 对 dave-desktop 的参考价值

### 技能管理面板设计参考

- 按分类展示技能（飞书/Cloudflare/书籍/AI框架/运维/兵法）
- 每个技能卡片显示：名称、大小、引用数、健康状态
- 支持按分类筛选、按引用数排序、按健康状态过滤

### 技能健康检查功能参考

- SKILL.md 存在性检查
- 引用文件完整性检查
- 命名冲突检测
- 循环依赖检测
- 缺失技能自动标记

### 技能市场/导入功能参考

- 支持从 `~/.agents/skills/` 标准路径导入
- 支持 SKILL.md 格式的技能包
- 技能分类元数据（category/tags/size/ref_count）

### 数据模型参考

```typescript
interface Skill {
  name: string
  category:
    | "lark"
    | "cloudflare"
    | "book"
    | "ai-framework"
    | "ops"
    | "art-of-war"
    | "zcode-plugin"
    | "other"
  sizeBytes: number
  referenceCount: number
  health: "healthy" | "missing-skill-md" | "broken-references" | "conflict"
  path: string
  tags: string[]
  description?: string
  lastModified?: string
}

interface SkillInventory {
  total: number
  healthy: number
  byCategory: Record<string, number>
  skills: Skill[]
}
```
